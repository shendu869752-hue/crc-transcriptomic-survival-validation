# Strict validation of a colorectal cancer transcriptomic survival score

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22827551.svg)](https://doi.org/10.5281/zenodo.22827551)

This repository contains the analysis code, validation tests, compact result tables, figure files, and environment records for the manuscript:

> Strict Validation of a Public-Data Colorectal Cancer Transcriptomic Survival Score Reveals Optimism, Feature Instability, and Probe-Mapping Sensitivity

The work is a methodological validation study. It does **not** provide a clinically deployable model, a fixed patient-level cutoff, or an absolute-risk calculator.

## Requirements

- R 4.6.1
- Windows PowerShell for the supplied launcher
- Approximately 10 GB of free disk space for downloads, prepared matrices, caches, and run artifacts
- Internet access for the initial public-data download

The exact package versions used for the certified run are in `reanalysis_v3/environment/sessionInfo.txt`. Install the required packages with:

```powershell
Rscript reanalysis_v3/environment/install_dependencies.R
```

## Full reproduction

From the repository root:

```powershell
.\run_v3_local.ps1 -Repeats 10 -BootstrapReps 2000
```

The launcher:

1. downloads the three external GEO series matrices;
2. downloads and reconstructs the GSE39582 and TCGA-COAD prepared inputs;
3. executes the complete primary and probe-mapping sensitivity pipelines;
4. writes a new content-derived run under `reanalysis_v3/runs/`.

The complete repeated nested-validation analysis is computationally intensive and can take several hours. A rerun can produce a different content-derived run key if software versions or the public source files have changed; compare the generated input and code manifests with the certified manifests before interpreting discrepancies.

## Tests

Run the portable regression suite with:

```powershell
.\run_tests.ps1
```

The formal run was independently validated with:

```powershell
Rscript reanalysis_v3/tests/validate_completed_run.R reanalysis_v3/runs/<run_key>
```

## Primary certified findings

- Development cohort: 573 patients and 190 deaths
- Apparent Harrell C-index: 0.694
- Median repeat-level out-of-fold C-index: 0.595
- Median within-repeat feature-set Jaccard similarity: 0.222
- External OS REML/Knapp-Hartung pooled HR per cohort-standardized SD: 1.286
- Adjusted pooled OS HR: 1.194
- Highest-mean sensitivity median out-of-fold C-index: 0.575

All claims should be interpreted with the limitations described in the manuscript, including cohort-adaptive external standardization, shared provenance of GSE17536 and GSE17537, limited clinical harmonization, and the absence of a prospective single-patient workflow.

## Portability note

The public release changes only machine-specific default paths in the acquisition and test launch code. The statistical analysis logic in `01_core_reanalysis_v3.R`, `utils.R`, `highest_mean_sensitivity.R`, and `build_submission_fig3.R` is unchanged from the certified formal run. Formal-run hashes remain available in `reanalysis_v3/results/code_manifest.csv`; release-specific hashes are recorded in `reanalysis_v3/manifests/release_manifest_sha256.csv`.
